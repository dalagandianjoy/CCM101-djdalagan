# Automation Research

## 1. Bash Script and Shebang

A Bash script is a file containing commands that Linux can execute to automate tasks. The line `#!/bin/bash` is called the shebang, and it tells the system to use Bash to run the script.

## 2. Variables

Variables store information that can be reused in a script. For example, `BACKUP_DIR="backups"` stores the name of the directory where backup files will be saved. The variable can then be referenced using `$BACKUP_DIR`.

## 3. Cron Job

A Cron job is a scheduled task in Linux that runs automatically at a specified time or date. It can be used to perform repetitive tasks, such as creating backups, without requiring the administrator to run the commands manually.
