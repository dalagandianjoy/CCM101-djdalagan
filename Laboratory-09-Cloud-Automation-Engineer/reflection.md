# Laboratory 09: Reflection

This laboratory helped me understand how automation makes cloud operations easier and more efficient. Managing hundreds of servers manually would take a lot of time, so automation allows engineers to perform repetitive tasks faster and more consistently. For example, a Bash script can create backups automatically instead of requiring an administrator to run the same commands every day.

However, automation also has risks. A small mistake in a script or command could affect many servers if it runs across 1,000 servers. It could delete important files, create incorrect backups, or interrupt services. Because of this, scripts should be checked and tested on a small scale before being used in a larger environment.

Bash scripting and Docker Compose serve different purposes. Bash scripts are useful for automating Linux commands and tasks, such as creating backups and managing files. Docker Compose uses a YAML file to define and manage applications made up of multiple containers. Both tools help reduce manual work, but they are designed for different needs.

After completing these cloud missions, I have a better understanding of cloud computing and the work involved in managing cloud infrastructure. I learned about Linux commands, networking, containers, deployment, monitoring, security, and automation. Each activity helped me understand how these concepts work together in real situations.

My favorite cloud engineering role is the Cloud Network Engineer because I am interested in networking and how devices and systems communicate. I want to continue improving my networking skills while learning more about cloud technologies. These activities have encouraged me to keep practicing and developing the skills I need for my future IT career.
