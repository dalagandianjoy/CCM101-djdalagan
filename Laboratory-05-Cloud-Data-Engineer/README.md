# Laboratory Activity 5: The Cloud Data Engineer

## Mission Overview

In this laboratory activity, I learned about different types of cloud storage and how object storage works. I also used Docker and MinIO to create my own object storage environment where I created a bucket and uploaded a sample file.

## Objectives

- Understand the differences between Block, File, and Object Storage.
- Deploy a MinIO object storage server using Docker.
- Access the MinIO Web Console using port forwarding.
- Create a storage bucket and upload a file.
- Practice documenting cloud storage activities using GitHub.

## Tools Used

- KillerCoda Ubuntu Playground
- Docker
- MinIO
- GitHub
- Web Browser

## Skills Learned

I learned how object storage can be used for storing files such as images and other unstructured data. I also learned how to deploy MinIO using Docker, access a service through a specific port, create a bucket, and upload an object. This activity also helped me become more familiar with using Docker commands and working with cloud storage.
