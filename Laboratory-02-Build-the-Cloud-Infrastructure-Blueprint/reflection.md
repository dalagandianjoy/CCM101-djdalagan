# Mission Reflection

1. Which cloud infrastructure component do you think is the most important? Why?

For me, networking is one of the most important components because it allows users, servers, and other cloud resources to communicate with each other. Without networking, users would not be able to access services that are running in the cloud.

2. How does Linux support cloud computing?

Linux supports cloud computing by providing an operating system where servers, applications, and services can run. During this activity, I used Ubuntu Linux in KillerCoda and different commands to check the server's CPU, memory, storage, network information, and other resources.

3. Why is technical documentation important before deploying infrastructure?

Technical documentation is important because it helps engineers understand the resources, configuration, and requirements of a system before deployment. It can also serve as a reference when troubleshooting problems or making changes to the infrastructure.

4. What new skills did you learn during this laboratory activity?

I learned how to investigate a Linux server using commands such as lscpu, free -h, df -h, findmnt, hostname, and hostname -I. I also learned more about compute, storage, networking, operating systems, and how AWS, Microsoft Azure, and Google Cloud provide similar cloud services under different names.

5. How has your GitHub portfolio improved after completing this mission?

My GitHub portfolio improved because I added another organized laboratory activity containing my infrastructure report, cloud component documentation, cloud provider comparison, reflection, and supporting evidence. I also practiced using Git commands to commit and push my work. This activity helped me become more comfortable using GitHub as a place to organize and document my cloud computing activities.
