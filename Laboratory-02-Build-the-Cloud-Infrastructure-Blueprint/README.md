Laboratory Activity 2: Build the Cloud Infrastructure Blueprint

Mission Overview

In this laboratory activity, I investigated a Linux server using KillerCoda to understand the basic components of cloud infrastructure. I also learned how compute, storage, networking, and operating systems work together in a cloud environment.

Objectives

- Investigate the resources available in a Linux server.
- Identify the main components of cloud infrastructure.
- Understand the purpose of compute, storage, networking, and operating systems.
- Compare the basic services offered by AWS, Microsoft Azure, and Google Cloud Platform.
- Practice documenting laboratory activities using Markdown and GitHub.

Cloud Infrastructure Components

The main cloud infrastructure components I learned about are compute, storage, networking, and the operating system. Compute provides processing power, storage keeps data and files, networking allows resources to communicate, and the operating system manages the hardware and software of the server.
