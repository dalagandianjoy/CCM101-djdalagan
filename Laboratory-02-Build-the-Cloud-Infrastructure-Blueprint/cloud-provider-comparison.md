 Cloud Provider Comparison

| Infrastructure Component | AWS | Microsoft Azure | Google Cloud Platform |
|---|---|---|---|
| Compute | Amazon EC2 | Azure Virtual Machines | Compute Engine |
| Storage | Amazon S3 | Azure Blob Storage | Cloud Storage |
| Networking | Amazon VPC | Azure Virtual Network | Virtual Private Cloud (VPC) |
| Identity and Access Management (IAM) | AWS IAM | Microsoft Entra ID / Azure RBAC | Google Cloud IAM |

Guide Questions

1. Which cloud provider offers the broadest range of services? Explain your answer.

For me, AWS offers the broadest range of services because it provides many options for computing, storage, networking, databases, security, and other cloud needs. It also has a wide variety of services that can be used by different types of organizations.

2. Which cloud platform would you recommend for an organization that primarily uses Microsoft products? Why?

I would recommend Microsoft Azure because it works well with Microsoft products and services. For an organization that already uses Microsoft technologies, Azure can make it easier to connect and manage their existing systems.

3. Which platform is widely recognized for Artificial Intelligence (AI), Machine Learning (ML), and Kubernetes services?

Google Cloud Platform is widely recognized for its AI, machine learning, and Kubernetes services. It provides tools for AI and ML and also offers Google Kubernetes Engine for managing containerized applications.

4. What similarities did you observe among the three cloud providers?

I observed that AWS, Microsoft Azure, and Google Cloud provide similar types of cloud services even though they use different names for them. All three provide services for computing, storage, networking, and identity and access management.
