# Mission Reflection

## 1. Which cloud platform impressed you the most?

The cloud platform that impressed me the most is Google Cloud Platform. I became interested in its services for AI, machine learning, and cloud computing. I also like that it provides different tools that can be useful for developing and managing applications.

## 2. What similarities exist among AWS, Azure, and GCP?

I learned that AWS, Microsoft Azure, and Google Cloud Platform provide many similar types of services. All three provide services for virtual machines, storage, networking, identity management, databases, and Kubernetes. Even though their services have different names, they can be used for many similar cloud computing tasks.

## 3. How do business requirements influence cloud platform selection?

Business requirements are important when choosing a cloud platform because every organization has different needs. For example, an organization that already uses Microsoft products may prefer Azure, while a company focusing on AI and machine learning may consider Google Cloud. Cost, existing technologies, and future growth can also affect the decision.

## 4. What did you learn from acting as a Cloud Solutions Consultant?

I learned that choosing a cloud provider is not only about selecting the most popular platform. It is important to understand the client's needs first and compare the services of different providers before making a recommendation. This activity helped me understand how technical decisions can be based on real business requirements.

## 5. How has your GitHub Cloud Computing Portfolio improved after completing this mission?

My GitHub portfolio improved because I added research and comparisons about AWS, Microsoft Azure, and Google Cloud Platform. I also documented my recommendations for different business situations and added another Linux investigation. My portfolio now shows more of what I have learned about cloud computing and how I can apply that knowledge to different situations.
