# Microsoft Azure Research

## Brief Overview

Microsoft Azure is a cloud computing platform developed by Microsoft. It provides different cloud services that organizations can use for computing, storage, networking, databases, security, and application development.

## Global Infrastructure

Microsoft Azure operates through different geographic regions around the world. These regions allow organizations to deploy their applications and resources closer to their users and support reliable cloud services.

## Cloud Management Console

The Azure portal is a web-based interface used to create and manage Azure resources. Users can use the portal to manage cloud services, monitor resources, configure applications, and view their Azure environment.

## Four Core Services

1. Azure Virtual Machines - Provides virtual computers that can run Windows, Linux, applications, and other workloads.

2. Azure Blob Storage - Provides object storage that can be used to store files and other unstructured data.

3. Azure Virtual Network - Provides private networking for Azure resources and allows resources such as virtual machines to communicate.

4. Azure Role-Based Access Control (Azure RBAC) - Helps control who can access Azure resources and what actions they are allowed to perform.

## Three Advantages

1. Azure integrates well with many Microsoft technologies and services.

2. It provides different cloud services for computing, storage, networking, security, databases, and other business needs.

3. Its global infrastructure allows organizations to deploy cloud resources in different geographic locations.

## Typical Enterprise Use Cases

Organizations can use Azure for hosting applications and websites, running virtual machines, storing and backing up data, managing databases, and connecting cloud resources. It can also be useful for organizations that already use Microsoft technologies and want to move some of their systems to the cloud.
