# Amazon Web Services (AWS) Research

## Brief Overview

Amazon Web Services (AWS) is a cloud computing platform that provides different services for organizations and developers. It allows users to access computing, storage, networking, databases, security, and other resources through the cloud.

## Global Infrastructure

AWS operates its cloud infrastructure in different geographic Regions around the world. Each Region contains multiple Availability Zones, which are separate locations that help improve the availability and reliability of applications and services.

## Cloud Management Console

The AWS Management Console is a web-based interface that allows users to access and manage AWS services. Through the console, users can create resources, configure services, monitor applications, and manage their cloud environment.

## Four Core Services

1. Amazon EC2 - Provides virtual servers that can be used to run applications and other workloads.

2. Amazon S3 - Provides object storage for storing and retrieving files and data.

3. Amazon VPC - Allows users to create and manage a virtual network for their AWS resources.

4. AWS IAM - Helps manage users, permissions, and access to AWS resources.

## Three Advantages

1. AWS provides a wide range of cloud services for different computing needs.

2. Its global infrastructure allows organizations to deploy applications in different geographic locations.

3. AWS allows organizations to increase or decrease cloud resources depending on their requirements.

## Typical Enterprise Use Cases

AWS can be used by organizations for hosting websites and applications, storing and backing up data, running virtual servers, hosting databases, and deploying business systems. It can also support organizations that need scalable infrastructure for applications used by many users.
