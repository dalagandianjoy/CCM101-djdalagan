# Google Cloud Platform (GCP) Research

## Brief Overview

Google Cloud Platform (GCP) is a cloud computing platform provided by Google. It offers different services for computing, storage, networking, databases, security, data analytics, artificial intelligence, and application development.

## Global Infrastructure

Google Cloud operates infrastructure in different regions and zones around the world. These locations allow organizations to deploy their applications and cloud resources closer to their users and support reliable services.

## Cloud Management Console

The Google Cloud console is a web-based interface used to create and manage Google Cloud resources. It allows users to access cloud services, configure resources, monitor applications, and manage projects from a browser.

## Four Core Services

1. Compute Engine - Provides virtual machines that can run applications and different workloads using Google's infrastructure.

2. Cloud Storage - Provides object storage for storing and retrieving files and other types of data.

3. Virtual Private Cloud (VPC) - Provides networking for Google Cloud resources such as virtual machines and other cloud services.

4. Identity and Access Management (IAM) - Helps control who can access Google Cloud resources and what actions they are allowed to perform.

## Three Advantages

1. Google Cloud provides services for computing, storage, networking, artificial intelligence, machine learning, and data analytics.

2. Its cloud resources can be scaled depending on the requirements of applications and organizations.

3. Its global infrastructure allows organizations to deploy applications and services in different geographic locations.

## Typical Enterprise Use Cases

Organizations can use Google Cloud for hosting applications, running virtual machines, storing data, performing data analysis, and deploying cloud-based systems. It can also support organizations that use artificial intelligence, machine learning, and containerized applications.
