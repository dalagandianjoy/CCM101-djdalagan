# Laboratory 01 - Welcome to the Cloud

# Mission Overview

This laboratory activity introduced me to a cloud-based Linux environment using KillerCoda. I learned how to navigate Linux, gather system information, organize files and directories, and prepare my Cloud Computing portfolio using GitHub.
# Objectives

- Access and use a cloud-based Linux environment.
- Explore and navigate the Linux operating system.
- Gather basic system information.
- Organize files and directories.
- Document technical work using Markdown.
- Create and maintain a GitHub repository.

# Activities Performed

- Launched Ubuntu 24.04 in KillerCoda.
- Created a Linux user with a home directory and sudo access.
- Logged in to the new user account.
- Checked the username, working directory, and hostname.
- Gathered Linux distribution, kernel, CPU, memory, and disk information.
- Created and organized Markdown files.
- Prepared a GitHub repository for my Cloud Computing portfolio.

# Skills Learned

I learned basic Linux navigation, user management, system information commands, file and directory organization, Markdown documentation, and the basic use of Git and GitHub for maintaining a technical portfolio.
