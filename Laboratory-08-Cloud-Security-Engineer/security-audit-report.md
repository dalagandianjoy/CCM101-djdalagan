# Security Audit Report

## 1. Principle of Least Privilege (PoLP)

The Principle of Least Privilege means giving users and applications only the permissions they need to perform their tasks. It is important in cloud environments because it reduces the risk of unauthorized access and limits the damage if an account is compromised.

## 2. Attack Surface

An attack surface refers to all the possible entry points that an attacker could use to access a virtual machine or its resources. Open ports, running services, and weak passwords can increase the attack surface and make the server more vulnerable to attacks.

## 3. Default Deny Policy

A Default Deny Policy blocks incoming network traffic unless a specific rule allows it. It is safer than blocking individual hackers because it also blocks unexpected connections that have not been explicitly permitted.
